☕ Java 17+

Exercícios

⚙️ Instalando o JDK

Para compilar e executar Java, instale o JDK (Java Development Kit):

  • Windows/macOS: baixe em adoptium.net (Eclipse Temurin) ou oracle.com/java.
  • Linux (Debian/Ubuntu): sudo apt install openjdk-17-jdk
  • Verifique com: java -version e javac -version

📦 Compilando e executando

Salve o arquivo como MinhaClasse.java (o nome deve ser igual ao da classe pública).

# Compilar javac MinhaClasse.java # Executar java MinhaClasse

O javac gera o bytecode .class, e java executa na JVM.

🧬 Estrutura do main

O ponto de entrada de qualquer aplicação Java:

public class Principal { public static void main(String[] args) { System.out.println("Olá, POO!"); } }

public static void main(String[] args) — público, estático, sem retorno, recebe array de Strings.

✏️ Convenções de código

  • Classes: PascalCase (ex: ContaBancaria)
  • Métodos e variáveis: camelCase (ex: saldoAtual, calcularJuros())
  • Constantes: UPPER_SNAKE_CASE (ex: TAXA_JUROS)
  • Pacotes: tudo minúsculo (ex: com.monitoria.poo)

🐛 Erros comuns

  • NullPointerException — chamar método em objeto null.
  • ArrayIndexOutOfBoundsException — índice fora do array.
  • NumberFormatException — conversão inválida (ex: Integer.parseInt("abc")).
  • ClassNotFoundException — classe não encontrada no classpath.
  • Erro de compilação: arquivo .java com nome diferente da classe pública.

🧪 Boas práticas

  • Uma classe pública por arquivo .java.
  • Atributos private, acesso via getters/setters.
  • Prefira StringBuilder em loops com muitas concatenações.
  • Use equals() para comparar Strings, nunca ==.
  • Comente o porquê, não o o quê.

🔤 Fundamentos da Linguagem

Variáveis e Tipos Primitivos

Java é estaticamente tipado — o tipo é declarado. Primitivos: int, double, boolean, char, long. Objetos: String, Integer, etc.

int idade = 25; double altura = 1.75; boolean ativo = true; char inicial = 'A'; String nome = "Ana";

Operadores

Aritméticos, comparação e lógicos. Destaque para / (divisão), % (resto) e operadores lógicos com curto-circuito && e ||.

7 + 3 // 10 7 / 2 // 3 (int) 7 % 2 // 1 2 * 3 // 6 5 > 3 && 2 < 4 // true !true // false

Condicionais

Use if, else if e else. Para múltiplos casos exatos, use switch (com break).

double nota = 7.5; if (nota >= 7) { System.out.println("Aprovado"); } else if (nota >= 5) { System.out.println("Recuperação"); } else { System.out.println("Reprovado"); }

Loops

for, while e do-while. Use break para sair e continue para pular a iteração.

for (int i = 0; i < 3; i++) { System.out.println(i); } int n = 0; while (n < 3) { System.out.println(n); n++; }

Strings

String é imutável em Java. Use equals() para comparar conteúdo. Métodos úteis: length(), substring(), toUpperCase(), split().

String texto = "Olá, Java!"; System.out.println(texto.length()); // 10 System.out.println(texto.toUpperCase()); // OLÁ, JAVA! System.out.println(texto.substring(0, 3)); // Olá // Comparação correta: if (texto.equals("Olá, Java!")) { ... }

Entrada e Saída

Saída com System.out.println(). Entrada com Scanner — lembre de importar java.util.Scanner.

import java.util.Scanner; Scanner sc = new Scanner(System.in); System.out.print("Nome: "); String nome = sc.nextLine(); System.out.print("Idade: "); int idade = sc.nextInt(); System.out.println(nome + " tem " + idade + " anos");

🗂️ Estruturas de Dados

Arrays

Tamanho fixo, tipo único. Índices começam em 0. Acesse com array[i] e descubra o tamanho com array.length.

int[] nums = {10, 20, 30}; System.out.println(nums[0]); // 10 System.out.println(nums.length); // 3 for (int n : nums) { System.out.println(n); }

ArrayList

Lista dinâmica da biblioteca padrão. Aceita apenas objetos (use wrappers como Integer). Métodos: add, get, remove, size.

import java.util.ArrayList; ArrayList<String> frutas = new ArrayList<>(); frutas.add("maçã"); frutas.add("banana"); System.out.println(frutas.get(0)); // maçã System.out.println(frutas.size()); // 2

HashMap

Pares chave-valor com acesso O(1). Métodos: put, get, containsKey, keySet.

import java.util.HashMap; HashMap<String, Integer> idades = new HashMap<>(); idades.put("Ana", 25); idades.put("Bruno", 30); System.out.println(idades.get("Ana")); // 25 System.out.println(idades.containsKey("Ana")); // true

HashSet

Conjunto sem duplicatas. Útil para remover repetições e testar pertencimento com contains.

import java.util.HashSet; HashSet<String> tags = new HashSet<>(); tags.add("java"); tags.add("java"); // ignorado System.out.println(tags.size()); // 1

Enums

Tipo com conjunto fixo de constantes. Ideal para naipes, dias da semana, status, etc.

enum Naipe { HEARTS, DIAMONDS, CLUBS, SPADES } Naipe n = Naipe.HEARTS; System.out.println(n); // HEARTS System.out.println(n.ordinal()); // 0 for (Naipe x : Naipe.values()) { System.out.println(x); }

For-each e Iteração

O for-each simplifica a iteração sobre arrays e coleções. Também funciona com Map.entrySet().

String[] nomes = {"Ana", "Bruno"}; for (String n : nomes) { System.out.println(n); } // Em um Map: for (var e : idades.entrySet()) { System.out.println(e.getKey() + " = " + e.getValue()); }

🧩 Métodos e Modularização

Métodos

Blocos reutilizáveis dentro de uma classe. Declaram tipo de retorno, nome e parâmetros. Use void se não retornar nada.

public static int somar(int a, int b) { return a + b; } public static void saudar(String nome) { System.out.println("Olá, " + nome); }

static vs instância

static pertence à classe; sem static pertence ao objeto. O main é sempre static.

class Contador { static int total = 0; int id; Contador() { total++; id = total; } }

Tratamento de Exceções

try/catch/finally captura erros e evita que o programa quebre. Exceções verificadas exigem tratamento ou throws.

try { int num = Integer.parseInt("abc"); System.out.println(10 / num); } catch (NumberFormatException e) { System.out.println("Número inválido!"); } catch (ArithmeticException e) { System.out.println("Divisão por zero!"); } finally { System.out.println("Fim."); }

Pacotes e imports

Pacotes organizam classes. Use import para acessar classes de outros pacotes. O pacote padrão é java.lang.

package com.monitoria.poo; import java.util.Scanner; import java.util.ArrayList; public class Principal { // ... }

Leitura de Arquivos

Use Files e Path (Java NIO) para ler e escrever arquivos. Mais moderno que FileReader.

import java.nio.file.*; import java.io.IOException; try { Files.writeString(Path.of("dados.txt"), "Olá\n"); String conteudo = Files.readString(Path.of("dados.txt")); System.out.println(conteudo); } catch (IOException e) { e.printStackTrace(); }

Generics

Permitem classes e métodos parametrizados por tipo, garantindo segurança em tempo de compilação.

class Caixa<T> { private T valor; public void guardar(T v) { valor = v; } public T pegar() { return valor; } } Caixa<String> c = new Caixa<>(); c.guardar("Olá"); System.out.println(c.pegar());

🏛️ Programação Orientada a Objetos

Classes e Objetos

Classe é o molde (atributos e métodos). Objeto é a instância concreta criada com new. O construtor tem o mesmo nome da classe.

public class Cachorro { String nome; public Cachorro(String nome) { this.nome = nome; } public void latir() { System.out.println(nome + ": Au au!"); } public static void main(String[] args) { Cachorro rex = new Cachorro("Rex"); rex.latir(); } }

Encapsulamento

Protege dados internos com private e expõe via public getters/setters. Controla o acesso e mantém invariantes.

public class Conta { private double saldo; public double getSaldo() { return saldo; } public void depositar(double valor) { if (valor > 0) saldo += valor; } }

Herança

Uma classe herda atributos e métodos de outra com extends. Use super(...) para chamar o construtor da superclasse.

public class Animal { public void comer() { System.out.println("Comendo..."); } } public class Gato extends Animal { public void miar() { System.out.println("Miau!"); } }

Polimorfismo

Uma referência da superclasse pode apontar para objetos da subclasse. O método executado é o da subclasse (sobrescrita com @Override).

class Animal { public void falar() { System.out.println("..."); } } class Cao extends Animal { @Override public void falar() { System.out.println("Woof"); } } Animal a = new Cao(); a.falar(); // Woof

Classes Abstratas

Definem contratos parciais. Não podem ser instanciadas. Métodos abstratos devem ser implementados pelas subclasses.

public abstract class Forma { public abstract double area(); } public class Circulo extends Forma { private double raio; public Circulo(double raio) { this.raio = raio; } @Override public double area() { return Math.PI * raio * raio; } }

Interfaces

Contratos puros com métodos abstratos (e default). Uma classe pode implementar várias interfaces — herança múltipla de tipo.

public interface Imprimivel { void imprimir(); } public class Relatorio implements Imprimivel { @Override public void imprimir() { System.out.println("Imprimindo..."); } }
